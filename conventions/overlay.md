# 浮层 / 面板 / 提示公约

> 除首屏之外的浮层（设置面板、菜单、提示、工具条、挂件）共享**顶层叠放与焦点**。冲突不表现为"被盖住"，
> 而表现为"点了没反应、Esc 关错了、焦点丢了"。

## 1. 共享资源与冲突面

- **共享资源**：顶层叠放顺序（z-index 空间）、焦点与键盘、点击命中。
- **实测到的现状**：生态里首屏类插件直接把 z-index 顶到 `2147483647` / `2147483000`。这类做法一旦被非首屏
  浮层模仿，会互相压住且没有仲裁者。
- **不归本模块管的**：首屏独占（见 [boot](./boot.md)）、背景层（见 [background](./background.md)）。

## 2. 叠放分级（本公约的核心约定）

| 层级 | z-index 建议范围 | 谁可以用 | 说明 |
|---|---|---|---|
| 背景层 | `-2` ~ `-1` | 背景类插件 | 必须在内容之下，见 background |
| 内容装饰 | `0` ~ `999` | 侧栏/输入区装饰 | 不改变命中 |
| 工具条 / 挂件 / 提示 | `1000` ~ `1999` | 可选浮层 | 不应盖住宿主弹层 |
| 宿主弹层之上 | `2000` ~ `2999` | 仅当确实需要 | 需说明理由 |
| 首屏 | 接近上限 | **仅首屏**，且必须走 [boot](./boot.md) | 独占资源 |

**禁止**：非首屏插件使用 `2147483000` 以上的常量。需要"必须在最上"时，用宿主插槽（如 `shell.overlay`）而不是抬数字。

## 3. 条目

### 3.1 非首屏浮层不得使用极端 z-index（必须）

**约定**：按第 2 节分级取 z-index；不使用 `2147483647` 一类常量。

**为什么**：一旦两个插件都这么干，谁在上面取决于挂载顺序，无法排查；而且会盖住宿主的弹层（包括审批框），
让用户"点不到确认"。

**怎么验**：打开插件浮层，再打开宿主设置/审批弹层：宿主弹层应在上。

### 3.2 必须可关闭，且 Esc 只关自己（必须）

**约定**：浮层支持 Esc 关闭；Esc 监听只在浮层打开期间生效，且 `stopPropagation` 只在自己是"最上层"时处理。

**为什么**：多个浮层同时监听 Esc 会出现"一次 Esc 关掉两层"或"关错层"。

**怎么验**：连开两个浮层，Esc 一次关一个。

### 3.3 关闭后必须恢复焦点（必须）

**约定**：打开前记录 `document.activeElement`，关闭后 `focus()` 回去。

**为什么**：焦点丢失后键盘用户与快捷键用户会"卡住"，且故障表现为"快捷键失效"，很难归因。

### 3.4 不常驻吃点击（必须）

**约定**：非交互区域 `pointer-events: none`；遮罩层若存在，必须能被点击关闭或明确可绕过。

**怎么验**：关掉浮层后界面完全可交互；浮层打开时背景不需要点击。

### 3.5 优先使用宿主插槽（建议）

**约定**：需要出现"在宿主层面"的浮层时，优先用宿主提供的插槽（例如 `shell.overlay`）与 Client Slots 服务，
而不是自己往 `body` 上挂。

**为什么**：宿主插槽自带层级、焦点与主题继承；自己挂必然要重新解决这三个问题。

### 3.6 提示类不要阻塞输入（建议）

**约定**：toast/提示放在不覆盖输入区的位置，自动消失且有最短显示时长；不要用模态遮罩做提示。

## 4. 配置口径

| 字段 | 默认 | 含义 |
|---|---|---|
| `overlay.zIndexBase` | 依分级 | 浮层基准层级 |
| `overlay.closeOnEsc` | `true` | Esc 关闭 |

## 5. 责任划分

| 事项 | 宿主负责 | 插件负责 | 仅使用该能力时适用 |
|---|---|---|---|
| 提供插槽与层级秩序 | ✅（部分） | | |
| 取合理 z-index | | ✅ | ✅ |
| Esc / 焦点恢复 | | ✅ | ✅ |
| 不常驻吃点击 | | ✅ | ✅ |

## 6. 参考实现：可嵌套、Esc 只关最上层

```js
var openLayers = []   /* 后进先出：只在最上层处理 Esc */

function openOverlay(onClose) {
  var previous = document.activeElement
  var layer = {
    close: function () {
      var i = openLayers.indexOf(layer)
      if (i >= 0) openLayers.splice(i, 1)
      try { previous && previous.focus && previous.focus() } catch (e) {}
      if (typeof onClose === 'function') onClose()
    },
  }
  openLayers.push(layer)
  return layer
}

document.addEventListener('keydown', function (e) {
  if (e.key !== 'Escape' || openLayers.length === 0) return
  var top = openLayers[openLayers.length - 1]
  e.stopPropagation()      /* 只处理一次，交给最上层 */
  top.close()
}, true)
```

## 7. 自测清单

- [ ] 同时打开插件浮层与宿主设置/审批弹层：宿主弹层在上、能操作
- [ ] 连开两层插件浮层：Esc 一次关一层，顺序正确
- [ ] 关闭后焦点回到打开前的元素，快捷键仍可用
- [ ] 关闭后界面完全可交互（无残留透明层吃点击）
- [ ] 浮层内文字在亮/暗主题下可读
- [ ] 窄窗/侧栏展开收起：浮层不溢出、不遮住输入区

## 8. 迁移与回退

- 从"抬 z-index 抢顶层"迁移到"分级 + 宿主插槽"：先按分级改数值，再把确实需要宿主层的搬到插槽。
- 回退：保留 `overlay.zIndexBase` 配置，用户遇到冲突可手动调整。
